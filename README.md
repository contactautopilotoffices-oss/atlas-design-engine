# Atlas Design Engine

Atlas Design Engine is the rendering, layout, and procedural generation engine powering Autopilot's property visualization, digital twin experiences, and architectural discovery.

## Overview

- **Engine Core**: Procedural 2D/3D layouts, digital twin rendering, and bundle-driven scene graphs.
- **Data Schemas**: Unified schema definitions for properties, spaces, and operational metrics.
- **Integrations**: High-fidelity map layers, CAD/DWG spatial alignment, and real-time configurators.

## Getting Started

### Prerequisites

- Node.js (>= 18)
- Python (>= 3.10, optional for spatial/data pipelines)

### Setup

```bash
# Clone the repository
git clone https://github.com/contactautopilotoffices-oss/atlas-design-engine.git
cd atlas-design-engine
```
